# onkhas1/homebrew-tap

Homebrew-рецепты от [onkhas1](https://github.com/onkhas1).

```bash
brew install onkhas1/tap/loftie
```

| Приложение | Что это |
|---|---|
| [Loftie](https://github.com/onkhas1/loftie) | Панель в челке MacBook: статусы, избранное, буфер обмена, музыка, запись мыслей голосом |
